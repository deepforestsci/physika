Standard Library
==========================

Physika provides standard library of reusable modules and utilities. The standard library
is located in the ``Physika/Std/`` directory.

Here is an example of how to import from the standard library:

.. code-block:: text

    from Std.linear_solvers import gaussian_solve



Linear solvers
---------------

The linear solvers module provides differentiable functions for solving linear systems.
The following functions are currently available:

* `Gaussian elimination method <https://github.com/deepforestsci/physika/blob/main/physika/Std/linear_solvers.phyk#L42>`_ 
* lu_decomposition
